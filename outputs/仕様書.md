# 字形工房 仕様書

## 目的

文字が規則正しい格子に並ぶ見本画像から字形を切り分け、線画を TrueType（`.ttf`）フォントとして端末内で作成するブラウザーアプリ。

## 利用者の流れ

1. `index.html` を対応ブラウザーで開く。
2. PNG、JPEG、WebP の見本画像を選ぶ。画像は同じ大きさの文字枠が格子状に並ぶものを想定する。
3. 列数、行数、左上から割り当てる Unicode 文字列を指定し、「字形を切り分ける」を押す。
4. 一覧から字形を選び、明度しきい値、大きさ、上下位置、字送りを調整する。調整値は各字形ごとに保持し、「全てに適用」で現在値を一括適用できる。
5. 字形一覧とフォント名を確認し、「フォントを書き出す」で `.ttf` を保存する。

## 構成ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面、格子分割、字形処理、調整操作、TrueType 書き出しを担う単一ページアプリ |
| `opentype.min.js` | OpenType.js。字形輪郭から TrueType データを組み立てる同梱依存ライブラリー |
| `OPENTYPE-LICENSE.txt` | 同梱ライブラリーの MIT 許諾文 |
| `変更記録.md` | 実装内容、検証状況、制約の記録 |

## 入出力と処理

- 入力: 利用者が選択した PNG/JPEG/WebP 画像、格子寸法、文字列、字形調整値。
- 内部処理: 画像をブラウザーの画像要素と Canvas に読み込む。格子ごとに画素を複製し、明度しきい値で透明背景と黒い前景を分ける。黒画素の境界を輪郭線へ変換し、OpenType.js で字形輪郭を含む TrueType フォントにする。
- 出力: ローカルのダウンロードとして `.ttf` を生成する。サーバーへの画像送信は行わない。
- 空白字形は標準の空白幅で生成する。字送り設定は各字形の進み幅に反映する。

## 画面部品

- 画像入力、分割数、文字の割当欄
- 字形一覧と選択状態
- 選択字形の見本、しきい値・倍率・上下位置・字送り調整
- 試し書き欄とフォント名
- TrueType 書き出し操作、ローカル処理の表示

## 技術上の前提と制約

- 外部サーバー、文字認識サービス、画像送信を使わず、処理はブラウザー内で行う。
- OpenType.js はローカル同梱している。書体を読み込む CDN は使わない。
- 文字位置の自動検出、傾き補正、背景の自動除去は実装していない。均等な格子への配置と分割数の指定が必要。
- 現在の実装は一文字一枠を想定する。合字、カーニング、異体字、上下左右の縦書き機能、ヒンティングは作成しない。
- CJK の任意文字も文字割当欄で指定できるが、試し書き表示は端末側フォントの代替表示になる場合がある。生成フォントの実用確認には書き出したファイルを実際の文字組み環境で確認する。
- ブラウザーが `file://` から同梱 JavaScript を読み込めない場合は、ローカル HTTP サーバーから開く。

## 依存関係

- OpenType.js 1.3.4（MIT License）を `opentype.min.js` として同梱。
- UI は HTML/CSS/JavaScript のみ。外部フォントの取得に失敗してもシステム書体で表示する。

## 設計根拠

Refero の画面・意匠検索を試みたが、契約が無効との応答があり、具体的な参照画面を取得できなかった。そのため、画像処理を中心に据えた暗色の作業面、明るい字形見本、工程番号、明確な操作状態を独自に構成した。画面例による裏付けは未取得。
