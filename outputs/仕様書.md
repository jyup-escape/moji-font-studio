# 字形工房 仕様書

## 目的

文字が規則正しい格子に並ぶ見本画像から字形を切り分け、Unicode の文字割当を持つ TrueType（`.ttf`）フォントとして端末内で作成するブラウザーアプリ。複数の文字体系の字形を一つのフォントへ収録できる。

## 利用者の流れ

1. `index.html` を対応ブラウザーで開く。
2. PNG、JPEG、WebP の見本画像を選ぶ。画像は同じ大きさの文字枠が格子状に並ぶものを想定する。
3. 列数、行数、左上から割り当てる Unicode 文字列を指定する。文字体系のひな型、直接入力、または文字一覧テキストを利用できる。重複文字は除かれる。選んだ文字数に応じて格子数を広げる。
4. 一覧から字形を選び、明度しきい値、大きさ、上下位置、字送りを調整する。調整値は各字形ごとに保持し、「全てに適用」で現在値を一括適用できる。
5. 字形一覧とフォント名を確認し、「フォントを書き出す」で `.ttf` を保存する。

## 構成ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面、格子分割、Unicode 文字割当、字形処理、調整操作、TrueType 書き出しを担う単一ページアプリ |
| `opentype.min.js` | OpenType.js。字形輪郭から TrueType データを組み立てる同梱依存ライブラリー |
| `OPENTYPE-LICENSE.txt` | 同梱ライブラリーの MIT 許諾文 |
| `変更記録.md` | 実装内容、検証状況、制約の記録 |

## 入出力と処理

- 入力: 利用者が選択した PNG/JPEG/WebP 画像、格子寸法、Unicode 文字列（最大 4,096 字）、字形調整値。文字一覧テキストは UTF-8 を推奨する。
- 内部処理: 画像をブラウザーの画像要素と Canvas に読み込む。格子ごとに画素を複製し、明度しきい値で透明背景と黒い前景を分ける。黒画素の境界を輪郭線へ変換し、OpenType.js で字形輪郭を含む TrueType フォントにする。
- 出力: ローカルのダウンロードとして `.ttf` を生成する。サーバーへの画像送信は行わない。
- 空白字形は標準の空白幅で生成する。字送り設定は各字形の進み幅に反映する。

## 画面部品

- 画像入力、分割数、文字の割当欄
- 字形一覧と選択状態
- 選択字形の見本、しきい値・倍率・上下位置・字送り調整
- 試し書き欄とフォント名
- TrueType 書き出し操作、ローカル処理の表示
- 文字体系ひな型、テキストファイル読込、200 字単位の字形一覧ページ切替

## 技術上の前提と制約

- 外部サーバー、文字認識サービス、画像送信を使わず、処理はブラウザー内で行う。
- OpenType.js はローカル同梱している。書体を読み込む CDN は使わない。
- 文字位置の自動検出、傾き補正、背景の自動除去は実装していない。均等な格子への配置と分割数の指定が必要。
- Unicode 文字列に含めた字形を、対応する符号位置で収録する。文字体系のひな型は一般的な Unicode 範囲から文字列を作る補助機能であり、その範囲全体を収録済みにする機能ではない。対応する字形画像を同じ順に格子へ用意する必要がある。
- ひな型はラテン基本・拡張、ギリシャ、キリル、アルメニア、ヘブライ、シリア、アラビア、デーヴァナーガリー、ベンガル、グルムキー、グジャラート、オリヤ、タミル、テルグ、カンナダ、マラヤーラム、タイ、ラオ、ミャンマー、クメール、エチオピア、ジョージア、モンゴル、ひらがな、カタカナ、ハングル音節、漢字の一部を用意する。ひな型の範囲は連続した Unicode 符号位置であり、各言語の文字頻度順や正書法上の完全な字母一覧ではない。
- 収録できる上限は一ファイル 4,096 字形。4,096 を超える漢字・ハングルなどは文字一覧と画像を分けて複数回作成する。
- 文字ごとに一つの輪郭を登録する。合字、カーニング、異体字選択、上下左右の縦書き、ヒンティング、右から左へ並べる処理、アラビア文字やインド系文字などの文脈依存の字形形成は作成しない。これらの文字体系では、出力フォントだけでは適切に表示できない場合がある。
- 試し書き欄は割当済みの字形を画像で表示する。割当のない文字は端末側の書体で代替表示される。
- 書き出した `.ttf` は画像からの輪郭化結果であり、文字体系の全字形を含む保証はない。実用前に、使用する機器・ソフトで字形や文字方向を確認する。
- ブラウザーが `file://` から同梱 JavaScript を読み込めない場合は、ローカル HTTP サーバーから開く。

## 依存関係

- OpenType.js 1.3.4（MIT License）を `opentype.min.js` として同梱。
- UI は HTML/CSS/JavaScript のみ。外部フォントの取得に失敗してもシステム書体で表示する。

## 設計根拠

Refero の画面・意匠検索を試みたが、契約が無効との応答があり、具体的な参照画面を取得できなかった。そのため、画像処理を中心に据えた暗色の作業面、明るい字形見本、工程番号、明確な操作状態を独自に構成した。画面例による裏付けは未取得。
